# Introduction to OA - Zero Trust Security for Identity

이 Tactical Guide는 설계 결정을 검토하고 Identity를 위한 Zero Trust Objectives를 구현하는 데 사용됩니다.

### Engagement Overview

이 문서는 Identity의 이 중요한 영역에 대해 식별된 Design & Implementation Components를 상세히 설명합니다.

### Document Purpose

이 문서의 목적은 보안을 강화하기 위해 식별된 Security Recommendations의 Design과 Implementation 방법을 상세히 설명하는 것입니다. 문서의 내용은 서비스 제공 과정에서 진행된 Customer Design Workshops와 Implementation Sessions에서 수집된 결정 사항과 정보에 기반합니다.

### Intended Audience

이 문서는 Microsoft Engineer와 Customer Identity Team, Security Team, Azure Architect Team, 그리고 여기 포함된 Recommendations를 실행할 책임이 있는 모든 Decision Makers 및 Solution Owners를 대상으로 합니다. 또한 Azure Governance, Identity, Monitoring에 대한 기본적인 실무 지식을 전제로 합니다.

- [Hybrid Identity](Hybrid-Identity)
